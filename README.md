# 夜参り（よまいり）

桜の夜の神社を歩いて、境内に置かれた六つの巻物を読む。全部読むと本殿の扉が開いて、祀られている三柱の由来が読める。

- ライブラリなし。描画は素の WebGL1、音は Web Audio API で合成
- モデルデータなし。鳥居・拝殿・本殿・灯籠・桜まで、すべて寸法からコードで生成
- PC は WASD + マウス (クリックで取り込み、Esc で解除)、スマホは画面左でスティック、右で視点

## 遊び方

1. 「鳥居をくぐる」で始める（音を鳴らすために一度タップが要る）
2. 境内を歩く。巻物のある場所に近づくと下に名前が出るので、`E` かボタンで開く
3. 拝殿の前では `R` で鈴、`F` で拍手
4. 六つ読んだら本殿へ。扉に触れると開く

## 構成

```

```

## 技術メモ

**ジオメトリ**  
すべて `MeshBuilder` に三角形を積んでいく。四角形は「法線がこちらを向くように巻き順を自動で直す」`quad()` を通すので、屋根のような曲面を関数で書いても面の向きが狂わない。屋根の反りは `1 - (1 - t)^1.5` で棟から軒へ落とし、唐破風は余弦の持ち上げに端の跳ね上がりを足した曲線。頂点レイアウトは位置・法線・色・発光・`sway` の 11 float で、`sway` は頂点シェーダーでの変形の種類（紙垂の風、鈴緒の振れ、本殿の扉の回転）を表す。

**ライティング**  
月光は平行光で、月の方向から境内全体を正射影したシャドウマップ（WebGL1 なので深度を RGBA に詰めている）を 3×3 PCF で参照する。提灯と灯籠は点光源で、毎フレーム視点に近い順に 8 個を選んでシェーダーに渡す。本殿の中の灯りは扉の開き具合に比例して強くなる。

**桜**  
花はポイントスプライト。木ごとに楕円の雲の中に 1000 点前後を撒き、頂点シェーダーで月光と点光源の影響を計算している。フラグメント側では五弁っぽい輪郭で切り抜く。花びらは同じシェーダーで `uFall` を立て、時間で落として折り返す。

**空**  
ピクセルごとに視線方向を求め、方向を格子に切って格子ごとに星を 1 つ置く。近い層と遠い層の 2 回撒いて瞬きを付ける。月は方向との内積で描く。

**ポストプロセス**  
シーンを FBO に描き、半解像度で SSAO、1/4 解像度で明部を抜いてガウスぼかし、合成時に FXAA・ACES トーンマップ・グレーディング・ビネット・粒子を掛ける。

**パフォーマンス**  
表面のむらは起動時に 256×256 の 4 チャンネルノイズを焼き、法線の向きで投影して 1 回の参照で済ませる (以前はピクセルごとに値ノイズを 5 回 = sin() 40 回)。桜は 1 枚の板に 16 輪を描く「房」を主体にして板の数を抑え、照明は花 1 輪ごとに頂点シェーダーで計算する (塗る面積が大きいので、フラグメントで光源を回すと支配的になる)。1 輪ずつの花は 22m より遠いと房に隠れて見えないので頂点シェーダーで畳んで消す。
シャドウマップは扉の開き具合が変わったときだけ描き直す。点光源は視点から 24〜34m で滑らかに消してから選外にするので、歩いても点いたり消えたりしない。フレーム時間が 22ms を超え続けると内部解像度を段階的に下げ、12ms を切れば戻す。巻物を読んでいる間は 30fps。境内の生成は Worker で行い、頂点は転送する。スマホは devicePixelRatio を 1.25 に抑え、シャドウマップも 1024 に落とす。

**気配**  
`js/omen.js` にまとめてある。出てくるものは一つも無く、光・音・間・向きだけで成立している。
見ていない間だけ進むもの (狛犬の向き、御神木の釘、伏せられる柄杓、消える灯明) は、視線と距離から「観測されていない」ことを確かめてから動かす。
巻物「正中」を読んだあとだけ、参道の中央を歩くと前方の灯りが奥から手前へ順に暗くなる。教わった規則を自分の意思で破ったときにだけ起きる。
六つ読み終えたあとに読み直すと、各巻の末尾に一文だけ増えている。六つ並べると一つの文になる。
本殿の御鏡は平面反射で背後の景色を正しく映す。一人称で身体を持たないので、見ている者だけが映らない。覗き込み続けると、鏡の中の扉だけが閉じていく。
本殿を出ると参道の灯りは消えていて、石畳には鳥居から本殿まで一人分の濡れた足跡が続いている。
風は常に吹いているのではなく、ときどき来るものにした。凪いでいる間は紙垂も止まり、たまに一枚だけがひとりでに揺れる。視界の外にある灯りがときどき一度消えて戻る (消える瞬間も点く瞬間も背後なので「さっきと違う」とだけ感じる)。本殿の扉が開く直前は虫も風も止み、その無音のあとに太鼓が鳴る。参道の脇の御神木には、参道からは見えない側に藁人形が打ち付けてある。

**音**  
環境音 (風と虫) は、実際の「夏の夜の田舎」と「風に揺れる草木」の録音を FFT で解析し、帯域ごとのレベルと包絡の周期を測ってから、その数値どおりに合成している。虫は 3.3-3.7kHz (約 6 回/秒) と 7-10kHz (約 21 回/秒) の二種類で、どちらも少しずつ音程と位相の違う個体を十数匹重ねたもの。12 秒ぶんを起動時に焼いてループさせる。止めることで無音の一瞬が作れる。録音そのものは解析にだけ使い、リポジトリには含めていない。
鈴は整数倍からずれた倍音の加算合成に短いノイズを重ねたもの。基音の違う小さな鈴を 4 つずらして鳴らすと、本坪鈴の「じゃらん」に近づく。太鼓は正弦波のピッチを急に落としたもの。

## 開発

```
npm test                       # ユニットテスト
python3 -m http.server 8080    # ES モジュールなので file:// では動かない
```

`main` に push すると GitHub Actions でテストが走り、通ったら GitHub Pages にデプロイされる。リポジトリの Settings → Pages → Source を **GitHub Actions** にしておく必要がある。

`?debug` を付けて開くと巻物を読まなくても本殿の扉に触れられる。`window.__yomairi` にプレイヤーの状態などを出しているのは、スクリーンショットの自動撮影と動作確認のため。

## 文章について

巻物の内容は、一般に知られている範囲の話に留めている。参拝の作法は神社によって違うので、断定は避けて「多くの神社では」の書き方にした。
